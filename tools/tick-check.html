Tick check

Decodes a tick clip with Web Audio, slices it by onset detection (the same slicer the game's audio.js uses), and checks the acceptance rule from the design: 6 or more clicks at least 150 ms apart, each falling below -40 dB (relative to its own peak) within 120 ms (wood) or 200 ms (metal, glass).

Query: ?family=wood|metal|glass&src=URL[,URL...]. Default src is ../game/assets/audio/sfx/sfx-ticks[-metal|-glass].mp3. It must be served over http (for example python3 -m http.server from the knit-knack folder). From script: await tickCheck(url, family) and await analyzeClip(url) return JSON.
